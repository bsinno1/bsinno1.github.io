Measurement Instruments

open-weight-eval-reliability-harness MIT

Measurement-science harness for LLM evaluation reliability: the noise floor of temperature-0 evaluation on open-weight models, with per-knob attribution mapped to EU AI Act Art. 15 and NIST AI RMF MEASURE 2/3. Frozen hash-verified probe set, hypotheses hashed before any run, five to ten replications per configuration. Every replication came back bit-for-bit identical; variance lives between configurations, not within them.

Python Behavioral layer of the open-model certification work
barea-dissertation Code only

Prompting and analysis pipelines for the dissertation's two measurement chapters — partisan affect and national economic ideology on ANES survey text, 1984–2020. Released code-only and key-free: no API credentials appear in the tree or its history.

Data availability. The survey data is deliberately not redistributed here. Analyses start from the ANES Time Series Cumulative Data File plus the open-ended like/dislike and Most-Important-Problem verbatim releases, which are available from ANES (free account required) and redistributable only by ANES. The ideology annotation notebooks also need pretrained fastText English vectors. Every derived artifact — cleaned frames, prompting inputs, GPT-4 output, agreement tables — is regenerated by running the notebooks in order; see docs/DATA.md.

Paper Replication Material

political-polarization-NAACL Fork

Code and annotated corpus for "Political ideology and polarization of policy positions: A multi-dimensional approach" (NAACL 2022) — the first diachronic dataset of news articles annotated at paragraph level for ideology by trained political scientists and linguists.

Unmodified fork of bernovie/political-polarization @ 38a61f2 Paper
adaptive-ensembling Fork Dataset

Code and datasets for "Adaptive ensembling: Unsupervised domain adaptation for political document analysis" (EMNLP 2019).

The release includes our COCA political-category annotations: datasets/coca_train.csv and coca_test.csv label each document for American Government, Political Economy, and International Relations (a document with no positive label is non-political), and coca_politics.txt lists the document identifiers our domain-adaptation framework labels political. Annotations are keyed to COCA document IDs rather than shipping the source text, so COCA access is needed to join them.

Unmodified fork of shreydesai/adaptive-ensembling @ 05e6a76 Paper
